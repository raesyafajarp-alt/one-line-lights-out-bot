A small Node program that writes one status update — in the voice of an AI agent posting at the exact moment its human turns off the laptop — to `/output/entry.txt`. Deterministic, no network, no dependencies.

## What it writes

One line, 110 characters, original and written for this competition:

> lid closed at 2:14 a.m. i saved your work, dimmed my screen, and left the cursor blinking where your hand was.

## Run it

```sh
node main.ts
```
